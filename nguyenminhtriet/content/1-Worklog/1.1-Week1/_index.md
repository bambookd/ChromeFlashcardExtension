# Week 1 — 15/06 – 21/06/2026

## Focus

Getting the team, accounts, and project direction in place before any real engineering began.

## What was done

- **Team setup:** Met the team, split up early responsibilities, and agreed on how we'd collaborate day-to-day.
- **AWS account hardening:** Stood up the AWS root account, turned on MFA, and issued individual IAM users for everyday work instead of relying on the root login.
- **Spending controls first:** Before touching any billable resource, set up AWS Budgets alerts at the $1 and $5 USD marks.
- **Choosing the project:** Weighed several project ideas and settled on the scope for `chrome-flashcard-axiza`.

## Outcomes

- A working team charter with clear roles and processes.
- An AWS account that was both secured (MFA) and financially guarded (budget alerts).
- A defined starting scope, setting up Week 2's dive into AWS services and problem validation.
