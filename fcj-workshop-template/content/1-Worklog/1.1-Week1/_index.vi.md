### Kết quả đạt được trong tuần 1:

* Nắm vững khái niệm về AWS và cấu trúc các nhóm dịch vụ nền tảng: 
  * Compute
  * Storage
  * Networking 
  * Database
  * ...

* Đã đăng ký và cấu hình thành công tài khoản AWS Free Tier.

* Thành thạo thao tác trên AWS Management Console, biết cách tìm kiếm và truy cập các dịch vụ qua giao diện web.

* Cài đặt và thiết lập thành công AWS CLI trên máy tính cá nhân, bao gồm:
  * Access Key
  * Secret Key
  * Region mặc định
  * ...

* Sử dụng AWS CLI để thực hiện các thao tác quản trị cơ bản:

  * Kiểm tra thông tin tài khoản và cấu hình hệ thống
  * Trích xuất danh sách các Region
  * Quản lý các tài nguyên EC2
  * Tạo mới và quản lý Key Pair
  * Theo dõi tình trạng các dịch vụ đang hoạt động
  * ...

* Kết hợp linh hoạt giữa giao diện Web Console và CLI để quản lý tài nguyên AWS một cách hiệu quả.
* ...
