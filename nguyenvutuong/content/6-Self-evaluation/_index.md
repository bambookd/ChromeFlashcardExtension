During my internship at AWS from **15 June 2026 to 31 July 2026**, I had the opportunity to apply the knowledge and skills acquired at university in a professional working environment. The internship also allowed me to gain practical experience with cloud computing, serverless application development, system deployment, security, monitoring, and technical documentation.

My main project was the development and deployment of the **ChromeFlashCardExtension — Serverless Flashcard Platform**. The project provides a Chrome extension that allows users to capture unfamiliar English vocabulary while reading online content and store it in a cloud-based flashcard system for later review.

The platform was supported by a serverless AWS architecture that included **Amazon API Gateway, AWS Lambda, Amazon DynamoDB, Amazon S3, Amazon CloudWatch, AWS IAM, and AWS SAM/CloudFormation**. I also worked with authentication, REST API development, infrastructure as code, cost monitoring, security controls, logging, and deployment automation.

Through this project, I strengthened my skills in:

* Serverless application design and cloud architecture
* REST API development and integration
* JavaScript and Node.js programming
* AWS service configuration and deployment
* Infrastructure as code using AWS SAM and CloudFormation
* Database design and data management with DynamoDB
* Identity and access management
* Application security and input validation
* Monitoring, logging, and troubleshooting with CloudWatch
* Technical analysis, testing, reporting, and documentation
* Communication, teamwork, and task management

One of my main achievements was delivering a functional project feature and deploying the application infrastructure to AWS. I gained experience in moving an application from a local development environment to a working cloud environment, identifying deployment issues, testing the system, and improving the solution based on technical findings and feedback.

Regarding my work ethic, I made a consistent effort to complete assigned tasks carefully and on time. I followed the established work processes, actively sought guidance when necessary, and communicated with colleagues to clarify requirements and improve the quality of my work. I also remained open to feedback and used it to improve both my technical skills and professional conduct.

## Areas for Improvement

I need to improve my discipline by managing time better and following workplace procedures more consistently. I should also develop a more systematic approach to problem-solving by identifying root causes and evaluating possible solutions before taking action. In addition, I need to communicate more clearly, provide timely progress updates, and explain technical issues in more structured way.


## Overall 

Overall, the internship was a valuable opportunity for me to connect academic knowledge with practical experience. By participating in the development and deployment of a serverless flashcard platform, I improved my understanding of AWS cloud services and gained greater confidence in developing, testing, documenting, and deploying a real application.

The internship also helped me recognise that professional growth depends not only on technical knowledge but also on discipline, communication, responsibility, teamwork, and the willingness to learn from feedback. In the future, I will continue improving these areas so that I can work more independently, solve problems more effectively, and make stronger contributions to future projects and teams.
