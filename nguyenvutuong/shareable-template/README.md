# External Internship Report — Shareable LaTeX Template

This folder is a clean, reusable version of the internship-report structure.
It contains no student data, company documents, signatures, or project
screenshots from the original report.

## Quick start

1. Edit only `metadata.tex` first.
2. Edit the placeholder text in `sections/`.
3. Put approved files in `assets/` when available:
   - `M1_cover_filled.pdf`
   - `D2.pdf`
   - `D3.pdf` when required
   - `signed_confirmation.pdf` after signing
4. Put product screenshots in `images/`.
5. Enable the corresponding options in `report-config.tex`.
6. Compile `main.tex` with XeLaTeX.

Do not submit the bracketed placeholder text. Before submission, search the
project for `\placeholder`, `TODO`, and square-bracket fields.

The school documents and each student's approved D2/D3 must be obtained
individually. They are intentionally not included in this template.
