\chapter{ASSIGNED TASKS AND IMPLEMENTATION}

\section{Problem Analysis}

The main problem was that learners often encounter unfamiliar vocabulary while
reading web pages, but switching to a separate note-taking app interrupts the
reading flow. Local browser storage alone also makes it difficult to persist,
sync, and review flashcards across devices and sessions.

The project addressed this by connecting a Chrome extension, a study web app,
and an AWS backend into one workflow for capture, synchronization, practice,
and export.

\section{Primary Implementation Flow}

\begin{enumerate}
  \item Capture text from the browser and create a flashcard in the extension.
  \item Store the card locally in \texttt{chrome.storage.local} so the user can
  continue working offline.
  \item Authenticate the user and synchronize unsent cards to the AWS backend.
  \item Study the cards in the web app and export them through a signed S3
  link when needed.
\end{enumerate}
