\section{Program Environment and Direction}

The program environment combined cloud engineering, web development, and
technical writing. The internship topic was closely aligned with computer
science because it required software design, frontend and backend integration,
cloud infrastructure, data modeling, and testing.

The work direction emphasized learning by building. I studied AWS services,
implemented the Chrome extension and study web application, deployed the
backend with AWS SAM, and documented the architecture and operational workflow
as the project evolved.

\section{Collaboration Model}

The work was organized around weekly milestones and review checkpoints. Team
members divided responsibilities across architecture, implementation, testing,
deployment, documentation, and presentation preparation.

I was responsible for completing assigned tasks, keeping the worklog updated,
and contributing to the project documentation set. When technical issues
appeared, I researched them first, then asked for clarification when needed and
updated the implementation or documentation accordingly.
