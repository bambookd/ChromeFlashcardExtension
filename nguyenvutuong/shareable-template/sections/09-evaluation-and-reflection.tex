\chapter{EVALUATION AND REFLECTION}

\section{Evaluation of the Internship Program}

The internship was relevant to my major because it combined software design,
cloud computing, and technical documentation. The program structure also
encouraged independent research, which helped me learn how to move from ideas
to a deployed system.

\section{Impression of the Company and Work Environment}

The environment was professional and practical. It encouraged learning through
task ownership, feedback, and iterative improvement, while still giving enough
room to research and solve problems independently.

\section{Recommendations}

Future students should start by understanding the full workflow before
implementing details, because this project depends on coordination between the
browser client, backend, and AWS infrastructure. I would also recommend more
frequent checkpoints for documentation and verification so the final report is
easier to complete.
