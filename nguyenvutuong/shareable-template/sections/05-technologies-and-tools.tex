\chapter{TECHNOLOGIES AND TOOLS}

\section{Client or Frontend Technologies}

\begin{itemize}
  \item Chrome Extension Manifest V3 for the browser extension architecture.
  \item JavaScript for the popup, background service worker, and content
  script logic.
  \item HTML and CSS for the extension UI and the study web application.
\end{itemize}

\section{Backend, Data, or Authentication}

The backend used Node.js and Express.js, with \texttt{serverless-http} to run
the API on AWS Lambda. JWT authentication protected private routes, while
Amazon DynamoDB stored users, flashcards, and categories. Amazon S3 was used
for private JSON exports through pre-signed URLs.

\section{Development and Testing Tools}

Git was used for version control, AWS SAM for build and deployment, and the
AWS CLI for verification and teardown. Chrome was used to load and test the
unpacked extension, while the static documentation site was maintained in Hugo
and LaTeX-based report files.
