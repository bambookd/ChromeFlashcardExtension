\section{Objectives}

\begin{itemize}
  \item Build an offline-first Chrome extension that captures flashcards while
  browsing and stores them locally.
  \item Design and deploy a serverless AWS backend for authentication,
  synchronization, retrieval, and export.
  \item Produce a complete set of technical documentation, workshop materials,
  and final internship evidence.
\end{itemize}

\section{Product or Work Scope}

The internship project was the Chrome Flashcard Extension & Study Platform.
The scope covered the browser extension, local offline storage, a study web
application, a Node.js Express backend, DynamoDB persistence, S3 export, API
Gateway, Lambda deployment, and a six-part workshop guide.

The report is based on the worklog, proposal, workshop documentation, blog
posts, event notes, self-evaluation, feedback, and references pages available
in the project content tree.
