\chapter{CONCLUSION AND FUTURE DIRECTION}

\section{Conclusion}

The internship produced a complete Chrome Flashcard Extension and Study
Platform on AWS, together with a documented workshop and final report. The
project demonstrated offline capture, cloud synchronization, active recall
study, secure export, and operational teardown.

It also strengthened my knowledge of cloud architecture, backend development,
deployment, testing, documentation, and teamwork.

\section{Limitations}

\begin{itemize}
  \item The report uses verified summary content rather than code-level source
  excerpts for every implementation detail.
  \item Some metadata fields in the template still require formal confirmation,
  such as the course code and supervisor names.
  \item The workshop documentation is focused on the approved internship scope
  and does not cover unrelated production features.
\end{itemize}

\section{Future Direction}

If the project continues, the most natural next steps would be improving the UI,
adding more study analytics, refining the deployment automation, and expanding
test coverage. Personally, I also want to improve my planning discipline and
become more confident in debugging larger cloud systems.

Before final submission, the report should be checked once more against the
approved internship records to ensure that all placeholders are removed,
ownership is stated correctly, and only approved non-sensitive evidence is
included.
