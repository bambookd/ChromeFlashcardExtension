# Week 3 — 29/06 – 05/07/2026

## Objectives

The objectives for Week 3 were to:

* Improve the core study experience of the flashcard application.
* Develop a clearer study-session workflow for reviewing vocabulary.
* Add category-management features to organise flashcards.
* Extend the Study web application with an additional test mode.
* Analyse the limitations of the current local-storage and local-backend implementation.
* Define a migration path from the local prototype to an AWS serverless architecture.
* Prepare an initial DynamoDB data model and AWS SAM template for future deployment.
