# Blogs Posted

### Overall

This section introduces the technical blogs published in the AWS Study Group
community during the internship.

### [Blog 1 — Understanding DDoS Protection in Amazon GameLift Servers](3.1-Blog1/)

Explains how Amazon GameLift Servers protects real-time multiplayer game traffic
from distributed denial-of-service attacks. The blog introduces Player Gateway,
token authentication, rate limiting, multiple relay endpoints, and dynamic
failover.

### [Blog 2 — AWS's Intelligent OCR Service](3.2-Blog2/)

Introduces Amazon Textract, an AWS machine learning service that extracts text,
handwriting, document layouts, forms, and tables from scanned or digital
documents. The blog discusses its main features, common use cases, practical
advantages, and limitations, including output post-processing and the lack of
Vietnamese-language support.

### [Blog 3 — Cloud Data Security: Understanding AWS Key Management Service](3.3-Blog3/)

Introduces AWS Key Management Service, a fully managed service for creating,
controlling, and rotating cryptographic keys. The blog explains hardware-backed
key protection, integration with AWS services, access control and auditing, the
envelope encryption process, and the difference between AWS KMS and AWS Secrets
Manager.
