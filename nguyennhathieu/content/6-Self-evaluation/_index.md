# 6. Self-Assessment

During my internship at AWS from **June 15, 2026 to August 2, 2026**, I had the invaluable opportunity to translate academic theory into practice within a fast-paced, enterprise cloud engineering environment. This experience enabled me to acquire hands-on proficiency across serverless system design, production deployment, cloud security, application monitoring, and technical documentation.

My primary project focused on designing, building, and deploying the **ChromeFlashCardExtension — Serverless Flashcard Platform**. The solution features an offline-first Manifest V3 browser extension that captures unfamiliar English vocabulary during web browsing and synchronizes it with a cloud backend for active recall review via a dedicated Web Application.

The platform is powered by a fully managed serverless AWS architecture, leveraging **Amazon API Gateway, AWS Lambda, Amazon DynamoDB, Amazon S3, Amazon CloudWatch, AWS IAM, and AWS SAM/CloudFormation**. Throughout the development lifecycle, I engaged directly with JWT token authentication, RESTful API design, Infrastructure as Code (IaC), cost governance, security controls, CloudWatch logging, and automated CI/CD pipelines.

Key engineering competencies I developed and strengthened during the internship include:

* **Serverless Architecture & Cloud System Design**
* **REST API Engineering & Client-Server Integration**
* **Modern JavaScript & Node.js Backend Programming**
* **AWS Managed Service Configuration & Infrastructure Management**
* **Infrastructure as Code (IaC) using AWS SAM & CloudFormation**
* **NoSQL Data Modeling with Amazon DynamoDB**
* **Identity & Access Management (IAM) & Least Privilege Enforcement**
* **Application Security, CORS Controls & Input Validation**
* **System Observability, Logging & Troubleshooting via CloudWatch**
* **Technical Documentation, Benchmarking & Integration Testing**
* **Agile Task Management, Technical Communication & Team Collaboration**

A primary achievement was delivering a fully functional application feature set and successfully provisioning its supporting AWS serverless infrastructure. Moving the application from a local sandbox to a live AWS cloud environment provided practical insights into diagnosing runtime edge cases, performing thorough integration testing, and refining software architectures based on empirical CloudWatch logs and feedback.

Regarding work ethic, I consistently aimed to complete all deliverables with high precision and within designated deadlines. I followed established operational workflows, proactively sought technical guidance when encountering roadblocks, and maintained transparent communication with teammates to align on requirements. Furthermore, I welcomed constructive feedback as an essential driver for improving both my technical skills and professional conduct.

## Summary & Future Outlook

Overall, the internship served as a pivotal experience in bridging academic knowledge with practical cloud software engineering. Developing and deploying a production-ready serverless flashcard platform deepened my understanding of AWS cloud architectures and built my confidence in designing, testing, documenting, and deploying real-world applications.

Beyond technical expertise, the internship demonstrated that long-term professional growth depends on discipline, effective communication, accountability, teamwork, and a continuous willingness to learn. Moving forward, I will continue refining these competencies to become an independent cloud engineer capable of solving complex technical challenges and contributing effectively to future engineering teams.
